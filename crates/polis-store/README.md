# polis-store

Polis Memory store: the SQLite schema for the hash-chained lake, the class catalog and the derived lexical layer; attaches to a host connection or opens standalone; cross-process-safe chain append.

Part of [Polis Memory](https://github.com/sersiousSenpai/polis-memory) — a local-first memory for coding agents. The README, the docs and the plan live in the repository; this crate is one layer of it.
