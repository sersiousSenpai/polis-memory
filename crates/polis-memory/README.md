# polis-memory

Polis Memory — the crate integrators add: the Polis handle implementing MemoryApi over the store, retrieval (the answer pack, timeline, map), the autonomous gardener (organize, compaction, observations, the semantic index), bundle export and the markdown mirror. Re-exports polis-core, polis-store, polis-llm and polis-embed.

Part of [Polis Memory](https://github.com/sersiousSenpai/polis-memory) — a local-first memory for coding agents. The README, the docs and the plan live in the repository; this crate is one layer of it.
