# polis-core

Polis Memory core: the hash-chained ledger vocabulary, the class-catalog proposal grammar, the answer-pack types and budget, bundle verification, and the MemoryApi trait. Pure — no I/O, no database.

Part of [Polis Memory](https://github.com/sersiousSenpai/polis-memory) — a local-first memory for coding agents. The README, the docs and the plan live in the repository; this crate is one layer of it.
