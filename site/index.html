Polis Memory

A local-first memory for coding agents: a hash-chained lake of every prompt and decision, an agent-organized class catalog over it, and batched retrieval across both — as Rust crates a host embeds, and as a polis daemon any harness reaches over MCP.

Install

curl --proto '=https' --tlsv1.2 -LsSf https://github.com/sersiousSenpai/polis-memory/releases/latest/download/polis-memory-installer.sh | sh
brew install sersiousSenpai/tap/polis-memory
cargo install polis-memory --features cli

Windows: powershell -ExecutionPolicy Bypass -c "irm https://github.com/sersiousSenpai/polis-memory/releases/latest/download/polis-memory-installer.ps1 | iex". Every artifact is sha256-checked and carries a GitHub attestation.

Then

polis init                          # ~/.polis: the store, a private token, your key
polis hook install                  # capture every prompt you submit in Claude Code
claude mcp add polis -- polis mcp   # answer questions about them, no daemon needed
polis doctor                        # the install, the chain, the backups, the clients

No model, key or network is needed for capture, retrieval or filing. Nothing leaves the machine unless you point it somewhere: no update check, no analytics.

Crates

CrateWhat it is
polis-coreThe pure vocabulary: ledger hashing, the proposal grammar, the answer pack, bundle verification, the MemoryApi trait. Verifies a bundle without SQLite.
polis-storeThe SQLite store: attach to a host connection or open standalone; its own migrations; the lexical layer; the cross-process-safe chain append.
polis-embedThe Embedder trait, on-device and remote backends, brute-force cosine search over an int8 index.
polis-llmThe Agent trait the gardener speaks: Claude Code and Codex CLI backends, Anthropic and OpenAI-compatible HTTP backends behind features.
polis-serverThe HTTP surface over MemoryApi, the ROUTES table, the capture route, the hook installer; the standalone daemon.
polis-mcpThe MCP server: read tools (memory_search first), scoped writes, resources and a grounding prompt over stdio or streamable HTTP.
polis-memoryThe crate integrators add: the Polis handle, retrieval, the autonomous gardener, backups and restore, identity and sharing, the polis binary.
